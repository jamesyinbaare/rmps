1. Overview

Use bulk upload to register many candidates at once from a spreadsheet. Download the Excel template from My school → Register → Bulk upload, fill it in, then upload it on the same page. You can also open these instructions in the portal or download this PDF separately.

Each successful row creates a candidate with status Incomplete. You still need to add photos (and pay fees where required) before registration is complete.

2. Step-by-step

  1. Download and open the Excel template (green headers = required, yellow = optional).
  2. Delete the sample rows and enter one candidate per row. Keep the header row unchanged.
  3. Save as .xlsx or .csv (UTF-8 for CSV).
  4. On the bulk upload page, set the default registration type if needed, then upload the file.
  5. Review the results table. Fix failed rows using the field name and message, then re-upload those rows.
Important rules
  • Use separate firstname and lastname columns — there is no single name column.
  • Dates must be DD/MM/YYYY (example: 15/01/2005).
  • Phone numbers must be 10-digit Ghana numbers starting with 0, with no country code (example: 0244123456).
    • {% if not is_private %}
  • For free_tvet and fee_paying, every row needs option: SOC or ENT (or C702 / C705).
    • {% endif %}

7. After upload

  • Successful rows create candidates with generated registration numbers and subject selections.
  • Failed rows are skipped; the results table shows the row number, field, and a short fix message.
  • Next steps in the portal: upload candidate photos, then complete fee payment where required.

Common mistakes

  • Putting the whole name in one column instead of firstname + lastname
  • Using 2005-01-15 instead of 15/01/2005
  • Entering +233244123456 or a number shorter/longer than 10 digits
    • {% if not is_private %}
  • Leaving option blank on free_tvet/fee_paying rows
    • {% endif %}
  • Using a programme code that does not exist or is not enabled for this exam

Green header cells in the Excel template are required; yellow headers are optional. Keep all cells formatted as text so leading zeros in phone numbers are preserved.
