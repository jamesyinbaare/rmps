# Registration Core Frontend

Next.js frontend for Registration Core (school/private registration, results publish/check, registration admin).

## Setup

```bash
npm install
```

Create `.env.local`:

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8002
```

```bash
npm run dev
```

App: http://localhost:3002

## Features

- School portal for bulk candidate registration
- Private registration for individual candidates
- Admin portal for exams, schedules, fees, results publishing
- Public results checking
